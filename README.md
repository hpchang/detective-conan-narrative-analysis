# 名偵探柯南 · 敘事架構分析

一份針對《名偵探柯南》敘事架構與時間軸的分析文件的**再查證與重建**。

原始素材是一份 AI 生成的英文分析文件，本專案做了三件事：

1. **來源分級** — 原文的 57 個引用被逐一標註等級（出版事實／正典彙整／次級彙整／社群推測）。近四分之一是 Reddit 討論串，卻與 Wikipedia 使用相同的陳述語氣。
2. **錯誤查證** — 對照日文正典與官方資料集，找出並修正五處實質錯誤。
3. **分層年表** — 依「事件確定性」重建時間軸，三層可切換。

## 五處已修正的實質錯誤

| # | 原文 | 修正後 |
|---|---|---|
| 1 | Karasuma Group（烏丸集團） | **黑衣組織**（烏丸是首領姓氏，非組織名） |
| 2 | 幹部級特工蘭姆（67 年前） | **當時仍是孩童的蘭姆**；代號世襲自其父 |
| 3 | 切下 `UMASCARA`，留下 `POTON` | **切下 `PTON`，留下 `UMASCARA`** |
| 4 | the organization Snake | **Snake 是個人代號**，不是組織 |
| 5 | bishop shogi piece | **角行**（將棋棋種，非西洋棋主教） |

其中第 3 項最值得一提：原文把「切下」與「留下」完全講反，並憑空多出一個 `O`。更重要的是它抹掉了這則死前留言的推理層次——`ASACA RUM`（淺香・蘭姆）是**會誤導人的初步解讀**，工藤優作指出這 8 個字母應合併讀作 `CARASUMA` ＝ **烏丸**，直指組織首領。
